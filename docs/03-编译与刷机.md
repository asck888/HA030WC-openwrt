# HA030WC OpenWrt 刷机指南

## 一、云编译（GitHub Actions）

### 1. 把项目传到 GitHub
```bash
# 在项目根目录初始化 git
cd HA030WC-openwrt
git init
git add .
git commit -m "HA030WC OpenWrt"
# 新建 GitHub 仓库后关联
git remote add origin https://github.com/你的用户名/HA030WC-openwrt.git
git push -u origin main
```

### 2. 触发编译
- 打开 GitHub 仓库 → **Actions** 标签
- 左侧选 **Build HA030WC OpenWrt**
- 点 **Run workflow** → 确认运行
- 等待约 1~2 小时

### 3. 下载固件
- 编译完成后，点进那个 workflow run
- 拉到最下面 **Artifacts** 区域
- 下载 `ha030wc-openwrt` zip
- 解压后里面有：
  - `openwrt-econet-en7528-nokia_ha030wc-squashfs-factory.bin` ← **网页升级用这个**
  - `openwrt-econet-en7528-nokia_ha030wc-squashfs-sysupgrade.bin` ← 以后系统升级用

## 二、刷机（推荐 Telnet 直刷）

### 前置条件
- TTL 线接好（救砖用）
- 电脑网线连路由器 LAN 口
- 电脑 IP 设为 192.168.10.5（或自动获取）

### 步骤 1：电脑上开 HTTP 服务器
把下载好的 `factory.bin` 放到一个文件夹，在该文件夹里运行：
```powershell
# Python HTTP 服务器
& "D:\Program Files\python\python.exe" -m http.server 8080
```

### 步骤 2：Telnet 登录路由器
```powershell
& "D:\Program Files\python\python.exe" telnet_router.py
```
用户名 `CMCCAdmin`，密码 `aDm8H%MdA`

### 步骤 3：下载固件到路由器
在 telnet shell 里执行：
```sh
cd /tmp
wget http://192.168.10.5:8080/openwrt-econet-en7528-nokia_ha030wc-squashfs-factory.bin -O /tmp/factory.bin
ls -la /tmp/factory.bin   # 确认大小
```

### 步骤 4：刷入
**先刷主银行（mtd2 kernel + mtd3 rootfs），保留从银行做备份：**
```sh
# 擦除并写入 kernel
mtd write /tmp/factory.bin kernel

# 擦除并写入 rootfs（如果 factory 镜像包含 rootfs）
# 注意：tclinux-ubi factory 镜像可能需要整体写入 tclinux 分区
# 先用这个试试：
mtd write /tmp/factory.bin tclinux
```

> **注意**：第一次刷如果不知道 factory 镜像怎么分区，先试 `mtd write factory.bin tclinux`。
> 如果不行，再试 `mtd write factory.bin kernel`。
> 刷完不要断电！

### 步骤 5：重启
```sh
reboot
```

## 四、救砖方案

### 情况 1：能 ping 通但进不了系统
- TTL 接好，上电看启动日志
- 如果 bootloader 正常，会在 3 秒内按任意键进 bootloader
- 按 `x` 进入 XMODEM 升级模式
- 用串口终端的 XMODEM 协议传送原厂 tclinux 备份

### 情况 2：完全没反应
- TTL 接好，上电
- 如果看到 `Press 'x' or 'b' key`，立刻按 `x`
- 进入 XMODEM 后，用 SecureCRT / TeraTerm 的 XMODEM 协议发送 `backup/mtd4_tclinux.bin`

### 情况 3：bootloader 都进不去
- 拆芯片，用 CH341A 编程器
- 刷回 `backup/mtd0_bootloader.bin`

## 五、备份文件位置

所有原厂分区备份在：
```
new-chat/backup/
├── mtd0_bootloader.bin      (256 KB)
├── mtd1_romfile.bin         (256 KB)
├── mtd2_kernel.bin          (3.4 MB)
├── mtd3_rootfs.bin          (13.8 MB)
├── mtd4_tclinux.bin         (25 MB)  ← 救砖用这个
├── mtd5_kernel_slave.bin    (3.4 MB)
├── mtd6_rootfs_slave.bin    (14 MB)
├── mtd7_tclinux_slave.bin   (25 MB)
├── mtd8_jffs2.bin           (15 MB)
├── mtd9_config.bin          (2 MB)
└── mtd10_reservearea.bin    (2.3 MB)
```

**刷机前务必确认这些备份文件还在！**
