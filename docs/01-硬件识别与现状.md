# 01 · 硬件识别与 OpenWrt 支持现状

## 一、硬件实测（主板照片 + TTL 启动日志双重确认）

| 项目 | 型号 / 规格 | 来源 |
|------|------------|------|
| 主控 SoC | **Econet EN7561DU**（bootloader 报为 EN7528 家族） | 丝印 + 日志 `EN7528 ... free bootbase` |
| 内存 | **128MB DDR3** | 日志 `DRAM size=128MB` |
| 闪存 | **Winbond W25N01G 128MB SPI NAND** | 日志 `mfr_id=0xef dev_id=0xaa W25N01G 0x8000000` |
| 5G 无线 | **MediaTek MT7613BEN**（PCIe） | 丝印 |
| 2.4G 无线 | MediaTek MT7603（PCIe，待 TTL `lspci` 确认） | 板上 U1 |
| 网口 | 2×LAN（黄）+ 1×WAN（蓝），全千兆 | 实物 |
| Bootloader | free bootbase v1.1（2021-05-10） | 日志 |
| 板子丝印 | HA-030W-C REV 1.0 | 实物 |

> 之前从照片误判为 256MB 内存 / 16MB NOR，TTL 日志纠正为 **128MB 内存 / 128MB NAND**。

## 二、OpenWrt 支持现状（好消息）

- OpenWrt 主线已有 **`econet` 目标**（2025-09 合入，内核 6.18）。
- **`en7528` 子目标已存在**，且本机 bootloader 自称 EN7528，属于同一家族。
- en7528 子目标用的就是：
  - **SPI NAND + UBI** 文件系统（`tclinux-ubi`）——和本机 W25N01G 对得上；
  - **`tclinux-free-bootbase-jump`** 内核打包步骤——和本机 "free bootbase" 对得上；
  - 小端 MIPS（mipsel），内核 `vmlinuz.bin`。
- 现有参考板：DASAN H660GM-A、JioFiber JCOW407/JCOW414（都是 mt7603+mt7615e）。

## 三、现在的路线（比之前清晰得多）

1. **先试 `en7528_generic` 通用镜像**：它已经开了 PCIe、千兆交换、NAND，内存先按 64MB 配（你有 128MB，少用一点也能启动）。这是最快的验证方式。
2. **不行就用本仓库的 `dts/en7528_nokia_ha030wc.dts`**：把内存改成 128MB、网口改成 2LAN+1WAN、NAND 分区按本机布局。
3. 两个镜像都用同一个 `files/` 定制层（AP 配置 + 极简网页 + 一键 MAC）。

## 四、刷起来后需要核对的两件事

1. **网口名**：启动后 `ls /sys/class/net/`，看 DTS 里 lan1/lan2/wan 标签和实际是否一致，不对就改 DTS 重新编译。
2. **无线**：`lspci` 看 PCIe 上的 MT7613BEN / MT7603 是否被识别，`wifi detect` 能否生成配置。

## 五、救砖

- TTL 能进 bootloader 命令行（上电按任意键）就能 TFTP 重刷，不会真砖。
- 第一步务必 `dd` 把整片 128MB NAND 读出来备份。
